# sn0w Shell

Quickshell is the coherent visual shell over Hyprland and system backends.

## Components

- Topbar
- Control Center
- launcher
- app switcher
- Overview
- OSD
- notifications
- clipboard UI
- screenshot/recording UI
- Project Center
- Containers panel
- Settings
- calendar/power surfaces

## Notifications

Transient popup only in normal operation. No Notification Center/history in V1.

## Control Center

Optimized for two-second actions: Wi-Fi, Bluetooth, sound, brightness, power profile, VPN, DND, battery, Settings and Power. It is not Grafana.

## Context awareness

General -> neutral shell.
Project -> compact project/Git/service context.
Activity -> relevant lightweight context such as media or gaming controls.
