# Keyboard & Gesture Contract

This file records intended UX, not yet exact Hyprland syntax.

| Shortcut | Action |
|---|---|
| ⌘Space | Launcher |
| ⌘Tab | App switcher |
| ⌘` | Cycle windows in current app (target) |
| ⌘↑ | Overview |
| ⇧⌥T | Ghostty |
| ⇧⌥V | VS Code |
| ⌘⇧V | Clipboard history |
| ⌘⇧3 | Full screenshot |
| ⌘⇧4 | Area screenshot |
| ⌘⇧5 | Capture/recording UI |
| ⌘⌥D | Containers panel (candidate) |

Application convention: ⌘C/V/X/Z/A/F and ⌘W/T/L should behave like macOS where feasible. Terminal convention: Ctrl+C/D/Z retain Unix semantics.

Gesture targets: 3-finger horizontal = workspace; 3-finger up = Overview; 3-finger down = close Overview.
