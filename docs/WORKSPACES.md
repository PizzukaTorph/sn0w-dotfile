# Context Workspaces

## Types

### General

Neutral workspace for transient/non-categorized activity. At least one General workspace should always be available.

### Project

Allocated dynamically to an active Project Session. Semantic name and project state may appear in Quickshell.

### Activity

Optional user-defined context for recreation or communication. Examples: Media, Gaming, Social.

Activity workspaces may be persistent or dynamic. Context can alter shell emphasis or make recommendations, but must not silently override explicit user choices.

Examples:

- Media: prominent media controls
- Gaming: optional DND/performance recommendation
- Social: communication apps

## Overview

Overview is the visual navigator for Context Workspaces. It should emphasize contexts and windows rather than expose implementation details such as raw workspace numbers.
