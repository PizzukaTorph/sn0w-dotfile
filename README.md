# sn0w

`sn0w` is a personal, developer-first Linux workstation shell for Apple Silicon.

The target machine is a MacBook Pro M1 Pro running Fedora Asahi Minimal. Fedora/Asahi owns hardware enablement; Hyprland owns compositing/window management; mature Linux services own networking, audio, storage, containers and secrets; Quickshell provides the coherent user-facing shell.

> **sn0w surfaces information and actions; it does not replace the tools that own them.**

This repository contains the specification, roadmap, dotfiles, shell configuration and bootstrap material needed to reproduce the environment.

Start with [`SPEC.md`](./SPEC.md) and [`ROADMAP.md`](./ROADMAP.md).
