# Hyprland config

Hyprland configuration will live here once the target Fedora Asahi installation is available for verification.

Do not paste random rice configs into this directory. Add config in tested slices: core -> input -> keybinds -> monitors -> lifecycle -> window rules -> context integration.

The current UX contract is documented in `docs/KEYBINDS.md` and `docs/INPUT_DISPLAY_POWER.md`.
