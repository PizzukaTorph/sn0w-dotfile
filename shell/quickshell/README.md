# sn0w Quickshell

This directory owns the visible sn0w shell.

Planned V1 surfaces:

- topbar
- Control Center
- launcher
- application switcher
- Overview / Mission Control
- toast notifications
- OSD
- Settings
- Containers panel
- Project Center

Quickshell must remain a frontend over system backends. It does not own networking, audio, Docker, secrets, power management or window management.
