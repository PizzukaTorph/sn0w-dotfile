# System integration

System-level integration belongs here: packages, portals, services, input/display/power glue, storage integration and lifecycle configuration.

Target structure:

```text
system/
├── packages/
├── portals/
├── input/
├── display/
├── power/
├── audio/
├── network/
├── storage/
├── secrets/
└── lifecycle/
```

Package names and service units must be verified against the actual Fedora Asahi Minimal installation before activation.
